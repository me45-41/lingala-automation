# Installation de LingalaAutomation

## 📦 Installation via npm

```bash
npm install -g lingala-automation
```

## 🚀 Utilisation Rapide

Compiler un fichier :
```bash
lingala mon-script.lingala
```

## 💻 Installation Locale

```bash
cd E:/gestion/lingala-automation
npm install
npm run build
node dist/cli.js scripts/mon-script.lingala
```

## 🌍 Pour les développeurs en RDC

LingalaAutomation est conçu pour rendre la programmation accessible en lingala. Pour commencer :

1. Installer Node.js
2. Installer LingalaAutomation
3. Créer votre premier script `.lingala`
4. Compiler et exécuter
