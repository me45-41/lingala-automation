# Suspension du Compte npm

## ⚠️ Problème
Votre compte npm a été temporairement suspendu avec le message :
```
Your account has been temporarily suspended due to a recent security-sensitive action.
```

## ✅ Solution : Contacter le Support npm

### Étape 1 : Vérifier votre compte
Allez sur https://www.npmjs.com/settings pour voir si votre compte est marqué comme suspendu.

### Étape 2 : Contacter le support npm
- Email : support@npmjs.com
- Portail de support : https://www.npmjs.com/support
- Expliquez que vous essayez de publier un package et que votre compte a été suspendu

### Étape 3 : Attendre la réactivation
npm vous informera par email une fois votre compte réactivé.
